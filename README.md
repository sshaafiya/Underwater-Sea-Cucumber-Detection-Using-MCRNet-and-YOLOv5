## 📌 Project Overview

Underwater object detection is challenging because of poor lighting, color distortion, suspended particles, and low visibility. This project addresses these issues by combining **MCRNet**, an underwater image enhancement model, with **YOLOv5**, a state-of-the-art object detection model, to accurately detect **sea cucumbers** in underwater environments.

The enhanced images generated by MCRNet improve visibility, enabling YOLOv5 to detect sea cucumbers more accurately than using raw underwater images.

---

## 🎯 Objectives

- Enhance underwater images using MCRNet.
- Detect sea cucumbers using YOLOv5.
- Improve detection accuracy under poor underwater visibility.
- Build an end-to-end underwater object detection pipeline.


Move into the project

```bash
cd Underwater-Sea-Cucumber-Detection
```

---

## 🚀 Training

Train the model using:

```bash
python main.py --stage both
```

or

```bash
python yolov5/train.py \
--img 640 \
--batch 8 \
--epochs 50 \
--data sea_cucumber.yaml \
--weights yolov5s.pt \
--name sea_cucumber_mcrnet
```

---

## 🔍 Detection

Run detection using the trained model:

```bash
python yolov5/detect.py \
--weights runs/train/sea_cucumber_mcrnet/weights/best.pt \
--source images/test.jpg
```
